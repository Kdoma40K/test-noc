# theme

Noctalia config for the NASA-punk theme. `config.toml` is currently **stock**
(a copy of Noctalia's `example.toml` at the pinned commit), so it's the
baseline: change it one step at a time and screenshot each step.

```bash
cd ../harness && ./shot.sh ../theme out/<step-name> steps/panels.txt
```

To use it on your PC, copy `config.toml` to `~/.config/noctalia/config.toml`
(Noctalia hot-reloads it).
