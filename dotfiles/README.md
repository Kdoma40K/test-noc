# dotfiles (branch `active-pc`)

Snapshot of the live configs on the **desktop PC** (NUC 11 Extreme, HDMI-A-2 4K@240, NVIDIA). The laptop (tinyputy) lives on `active`; don't merge one into the other wholesale: monitor names, scale, polkit/keyring and fish config differ. Every change here gets synced and pushed to `active-pc`.
synced here and pushed so there is a history of it.

```bash
./dotfiles/sync.sh                      # copy live files in + refresh package lists
git add -A dotfiles && git commit -m "what changed" && git push
```

Paths under `home/` mirror `~`, `etc/` mirrors `/etc`. To restore a file, copy it back.

| File | What it is |
|---|---|
| `home/.config/noctalia/config.toml` | Noctalia shell: frosted glass theme (telemetry plugin removed), bar layout |
| `home/.local/state/noctalia/settings.toml` | Noctalia GUI settings (win over config.toml): wallpaper, plugins, templates, dock |
| `home/.config/hypr/hyprland.lua` | Hyprland: gaps, blur, rules, autostart, env |
| `home/.config/hypr/custom/noctalia-blur.lua` | Blur layer rules behind Noctalia surfaces |
| `home/.config/kitty/kitty.conf` | Kitty terminal (opacity 0.80) |
| `home/.config/foot/foot.ini` | Foot terminal |
| `home/.config/fish/config.fish` | Fish shell: starship prompt, eza aliases |
| `home/.config/starship.toml` | Starship prompt |
| `home/.config/qt5ct/qt5ct.conf`, `qt6ct/qt6ct.conf` | Qt app theming |
| `home/.config/mimeapps.list` | Default apps |
| `home/.config/gh/config.yml` | GitHub CLI settings (no tokens) |
| `home/.config/zen/profile/` | Zen browser glass: `user.js`, `chrome/userChrome.css`, `userContent.css` |
| `home/.local/share/applications/yazi.desktop` | Yazi launcher entry (file manager) |
| `etc/greetd/config.toml` | Login screen: greetd running noctalia-greeter |
| `packages/pacman.txt`, `packages/aur.txt` | Explicitly installed packages |

Not tracked (generated by Noctalia on theme change): `hypr/noctalia.lua`, `kitty/themes/noctalia.conf`,
`qt*ct/colors/noctalia.conf`, `~/.cache/noctalia/zen-browser/`.
The theme source (fonts, palettes, plugin) lives in `theme/` and `plugins/` on main.
